# 设备管理

## 查找设备

1. 用 USB 数据线连接 USB 灯牌，或给蓝牙灯牌供电并打开电脑蓝牙。
2. 在 AI Light 左侧选择“设备”。
3. 等待自动查找，或选择“重新查找设备”。

USB 和蓝牙分别查找，设备出现后即可连接。查找期间按钮会暂时不可用并显示进度，结果列表显示已识别的 AI Light 状态灯。如果没有找到状态灯，请查看[故障排查](./troubleshooting.md#找不到-ai-light-设备)。

## 连接设备

在目标设备旁选择“连接”。AI Light 会与灯牌握手，读取设备能力并同步当前灯效。

连接成功后可以看到：

- “设备”页面显示“已连接”；
- 侧栏底部显示“设备已连接”；
- 状态页面出现设备信息；
- 试听操作可以控制实体状态灯。

AI Light 当前一次只连接一台设备。连接另一台设备时，应用会切换到新的连接。

USB 灯牌沿用蓝牙设备的主题、提示音和试听操作。设备能力决定灯光亮度上限和蜂鸣是否可用。

选择“读取硬件状态”可查看场景状态、三颗灯的 RGB、蜂鸣状态和会话租期。蜂鸣播放时同时显示固件报告的频率和驱动强度。

## 断开连接

在已连接设备卡片中选择“断开连接”。这会停止当前连接和自动重连，但保留设备记录。下次启动 AI Light 时，应用仍会尝试自动连接这台设备。

## 忘记设备

选择“忘记设备”，再在确认窗口中选择“确认忘记”。应用会：

1. 停止自动重连；
2. 断开当前设备；
3. 清除已记住的设备。

忘记后，下次使用需要重新查找和连接。如果断开操作失败，应用不会删除设备记录，以免留下不一致状态。

## 电量、信号与故障

设备信息可能包含：

- 电量百分比；
- 当前供电或充电状态；
- 蓝牙信号强度；
- 最近同步时间。

“设备”页面显示灯牌报告的故障。蓝牙可能报告灯光、蜂鸣器、电源或内部通信故障。USB 在连接期间检查故障位，显示灯光驱动、蜂鸣驱动或内部协议故障，恢复时自动清除告警。问题持续时，可以记录提示信息和应用版本并提供给支持人员。

## 自动重连

意外断连时，AI Light 先执行最多 5 次快速重连。已记住的 USB 灯牌在快速阶段结束后进入长期等待，同一块灯牌接回即可恢复。主动停止重连、断开连接或忘记设备会结束等待。

## 开发板联调

调试构建可显式登记开发板 VID/PID。下例对应开发固件的 USB 标识。

```bash
AILIGHT_USB_VID=1A86 AILIGHT_USB_PID=FE07 pnpm tauri dev
```

正式构建通过编译环境登记获授权的产品 VID/PID。Linux 普通用户还需要对应 VID/PID 的 hidraw 访问权限。
