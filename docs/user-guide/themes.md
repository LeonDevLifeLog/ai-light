# 主题与提示音

主题决定每种任务状态应该显示什么灯光、动画和声音。切换主题不会改变任务状态本身。

## 选择内置主题

打开“主题”页面，选择一个主题并点击“使用此主题”。当前状态不是空闲时，新主题效果会立即同步到设备。

| 主题 | 风格 | 适合场景 |
|---|---|---|
| Default 经典 | 均衡、容易识别 | 初次使用和日常办公 |
| Minimal 极简 | 白灰色、几乎无声 | 安静环境和低干扰需求 |
| Focus 专注 | 低亮度、单灯表达 | 深度工作 |
| Nature 自然 | 柔和、变化缓慢 | 对强光敏感的环境 |
| Aurora 极光 | 三灯异色流动 | 喜欢多彩效果 |
| Neon 霓虹 | 高饱和、节奏醒目 | 需要强提醒的环境 |

主题的实际表现以“主题”页面预览和实体设备试听为准。

## 试听主题

- 软件预览可以查看灯光变化；
- 连接设备后，可以在实体状态灯上试听；
- 含提示音的主题可能在完成或出错时发声；
- “试听”页面适合依次检查每个标准状态。

## 以现有主题创建自己的主题

1. 在“主题”页面选中一个主题。
2. 选择“以此主题创建”或“以当前主题创建”。
3. 输入主题标识。
4. 选择要编辑的状态。
5. 调整动效、速度、颜色、亮度、灯光顺序和声音。
6. 在右侧预览，连接设备后也可以在设备上试听。
7. 选择“保存主题”。

标准状态会固定保留，也可以添加自定义状态。主题标识建议只使用英文字母、数字、连字符或下划线，并保持唯一。

## 编辑效果

主题创作器提供以下常用选项：

- **动效**：常亮、呼吸、闪烁、流动、渐亮、渐弱；
- **速度**：舒缓、适中、活跃；
- **灯光**：分别设置顶灯、中灯和底灯的开关、颜色与亮度；
- **顺序**：一起、从上到下、从下到上、交错；
- **声音**：无声、轻提示、确认音、警报音；
- **借用主题效果**：把另一主题某个状态的效果复制到当前状态；
- **逐灯精确调整**：面向熟悉灯效参数的高级用户。

如果多个状态共用同一套效果，修改可能同时影响它们。需要单独编辑时，先选择“让本状态独立”。

关闭存在未保存修改的创作器时，应用会询问是否放弃修改。

## 导入主题

1. 在“主题”页面选择“导入主题”。
2. 选择 `.ailight-theme.json` 文件，或粘贴完整主题 JSON。
3. 确认导入。

导入失败的常见原因包括：

- JSON 内容不完整或格式错误；
- 主题字段或参数不合法；
- 主题引用了不存在的效果；
- 主题名称与内置主题冲突。

内置主题不能被同名用户主题覆盖。高级格式说明见[主题文件参考](./reference/theme-files.md)。
