# 接入 AI 编程工具

AI Light 当前面向最终用户提供 Claude Code 和 Codex 的一键接入。连接成功后，工具的工作、等待、完成和失败状态会自动同步到 AI Light。

## 开始之前

请确认：

- 目标 AI 编程工具已经安装；
- AI Light 应用正在运行；
- 电脑已安装 Node.js 和 npm；
- 首次安装配套组件时可以访问 npm 软件源。

## 连接 Claude Code

1. 打开“接入”页面。
2. 找到 Claude Code 卡片。
3. 选择“连接”。
4. 等待卡片显示“已连接”。
5. 新建一次 Claude Code 任务，检查 AI Light 状态是否变化。

## 连接 Codex

1. 打开“接入”页面。
2. 找到 Codex 卡片。
3. 选择“连接”。
4. 等待卡片显示“已连接”。
5. 新建一次 Codex 任务，检查 AI Light 状态是否变化。

实际可用能力取决于本机 Codex 版本及其 Hook 支持情况。云端运行、没有经过本机 Hook 的任务不会自动同步。

## 连接操作会修改什么

AI Light 会安装或调用配套组件，并在目标工具的配置中加入由 AI Light 管理的 Hook。配置写入采用合并方式：

- 不覆盖已有的其他 Hook；
- 重复连接不会反复添加相同配置；
- 配置变更前会保留必要备份；
- AI Light 不可用时，不应阻断 AI 编程工具本身的运行。

日常使用不需要知道服务端口，也不需要手动填写网络地址。

## 断开接入

在已连接的工具卡片中选择“断开”。AI Light 只删除自己管理的 Hook，保留工具中的其他配置。

断开 AI 编程工具不会：

- 卸载 AI Light 应用；
- 断开 AI Light 设备；
- 删除用户主题；
- 删除目标工具的其他 Hook。

## 如何确认同步正常

不要只看“已连接”标签。完整验证应包含：

1. 发起真实任务；
2. “状态”页面变为“工作中”；
3. 请求授权或输入时变为“等你回复”；
4. 任务结束时变为“已完成”或“出错了”；
5. 已连接的实体状态灯同步变化。

如果卡片显示已连接但任务状态不变化，请查看[接入已连接，但任务状态不更新](./troubleshooting.md#接入已连接但任务状态不更新)。
