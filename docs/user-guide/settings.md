# 个性化设置

AI Light 的设置会即时生效并自动保存。保存失败时，界面会恢复原值并显示原因。

## 多个工具同时运行时

多个 AI 编程工具同时运行时，AI Light 固定显示最近发生变化的工具状态；最后上报状态的工具会接管状态灯。当前版本不提供切换仲裁策略的设置。

同一个工具会跟随它最新的任务状态。

## 外观模式

可以选择：

- 亮色；
- 暗色；
- 跟随系统。

外观模式只改变 AI Light 应用界面，不会改变实体状态灯主题。

## 灯组朝向

可以选择横向或纵向。这项设置改变状态总览和托盘中的灯组排列，不改变实体设备的安装方向或灯效顺序。

## 当前主题

设置页会显示当前主题的颜色预览。点击该项可前往“主题”页面进行切换或编辑。

## 开机自启

开启后，AI Light 会在登录操作系统后自动运行，并在后台准备接收状态和连接设备。

如果切换失败：

1. 检查系统是否允许应用管理登录启动项；
2. 确认应用仍位于原安装位置；
3. 在系统登录项设置中检查 AI Light；
4. 重新打开应用后再试。

关闭主窗口不会退出应用。若要停止后台运行，请从托盘菜单选择“退出”。

## API 接口文档

“打开文档”会在浏览器中打开当前运行中的本机 Hook API 说明，主要用于自定义接入和排障。日常使用无需打开，也无需配置端口或网络地址。

## 外部运行环境

在“系统”区域可以展开“运行环境详情与操作”，查看 Node.js、npm 和 Adapter 的路径、版本、检测来源与检测时间。

- “重新检测”会保留手动指定的路径并重新验证；
- “恢复自动检测”会清除手动指定的路径，再重新搜索系统环境；
- Adapter 已可用时，可以主动“检查更新”。只有点击检查时才会访问 npm registry，不会自动升级；发现兼容版本后，选择“升级至”完成更新。

如果配置文件损坏，界面会提供“重建配置并检测”，并在重建前保留原配置以便排查。
