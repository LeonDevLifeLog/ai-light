# 个性化设置

AI Light 的设置会即时生效并自动保存。保存失败时，界面会恢复原值并显示原因。

## 多个工具同时运行时

这一设置决定多个 AI 编程工具状态冲突时显示谁：

- **重要状态优先**：优先显示更需要注意的状态，适合希望错误和完成提示不被轻易覆盖的用户；
- **最近活动优先**：显示最近发生变化的工具，适合频繁在多个任务间切换的用户。

无论选择哪一种，同一个工具都会跟随它最新的任务状态。

## 连接安全

AI Light 的任务状态服务只接受来自本机的连接。普通用户不需要配置端口或网络地址。

“接口文档”会在浏览器打开当前运行中的高级接口说明，主要用于自定义接入和排障。日常使用无需打开。

## 外观模式

可以选择：

- 亮色；
- 暗色；
- 跟随系统。

外观模式只改变 AI Light 应用界面，不会改变实体状态灯主题。

## 灯组朝向

可以选择横向或纵向。这项设置改变状态总览和托盘中的灯组排列，不改变实体设备的安装方向或灯效顺序。

## 当前主题

设置页会显示当前主题的颜色预览。点击该项可前往“主题”页面进行切换或编辑。

## 开机自启

开启后，AI Light 会在登录操作系统后自动运行，并在后台准备接收状态和连接设备。

如果切换失败：

1. 检查系统是否允许应用管理登录启动项；
2. 确认应用仍位于原安装位置；
3. 在系统登录项设置中检查 AI Light；
4. 重新打开应用后再试。

关闭主窗口不会退出应用。若要停止后台运行，请从托盘菜单选择“退出”。
