# 日常使用

## 查看当前状态

打开“状态”页面，可以看到当前任务状态、来源、设备连接情况和正在使用的主题。

| 状态 | 代表什么 | 常见默认表现 |
|---|---|---|
| 空闲 | 当前没有需要展示的任务 | 熄灭 |
| 工作中 | AI 正在思考或执行 | 呼吸灯 |
| 等你回复 | AI 需要输入、确认或授权 | 黄色提示 |
| 已完成 | 本轮任务正常结束 | 绿色常亮 |
| 出错了 | 本轮任务没有正常完成 | 红色闪烁 |

具体灯色、动画和声音由当前主题决定。状态名称才是准确语义，颜色不是唯一判断依据。

## 多个工具同时运行

同一个 AI 工具会按它最新上报的生命周期状态推进。例如，它可以从“工作中”进入“等你回复”，再进入“已完成”。

多个工具同时运行时，AI Light 固定展示最近发生变化的工具；最后上报状态的工具会接管状态灯。无需额外设置。这个规则只影响多个工具发生冲突时显示谁，不会改变单个工具自身的状态推进。

## 使用系统托盘

关闭主窗口不会退出 AI Light。应用会继续在系统托盘或菜单栏运行，保持接收任务状态和连接设备。

托盘菜单可以用于：

- 显示主窗口；
- 查看当前状态和主题；
- 查看设备连接情况；
- 调整灯组朝向；
- 打开设备配置；
- 退出 AI Light。

需要彻底结束应用时，请从托盘菜单选择“退出”。

## 设备断开后的表现

连接意外中断后，AI Light 会自动尝试重新连接，最多尝试 5 次。“设备”页面会显示正在自动重连。

你可以：

- 等待自动恢复；
- 选择“停止重连”；
- 选择“忘记设备”，清除自动连接记录。

设备重新连接成功后，应用会重新同步当前状态效果。

## 手动测试状态

“试听”页面可以模拟五种标准状态和自定义状态：

- 选择状态按钮会改变应用当前状态；
- “试听当前灯效”只重播灯光和声音；
- “停止灯效”会停止输出并恢复为空闲；
- 当前主题没有自定义状态映射时，会使用空闲效果。

手动测试会改变当前展示状态，测试完成后建议选择“停止灯效”。
