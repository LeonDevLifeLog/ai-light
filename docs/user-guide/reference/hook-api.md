# 高级接入参考

> 本章面向需要接入其他工具或编写自动化的高级用户。Claude Code、Codex、Qoder 和 WorkBuddy 用户应优先使用应用中的“一键连接”。

AI Light 应用会在本机启动状态服务。服务只监听 `127.0.0.1`，不会直接接受其他电脑的连接。默认优先使用端口 `25679`；如果端口被占用，应用会自动选择后续可用端口，因此自定义接入不应把端口写死。

## 查看当前接口文档

1. 打开 AI Light“设置”。
2. 展开高级服务信息。
3. 选择“打开接口文档”。

浏览器中的接口文档对应当前正在运行的实际地址，适合查看请求格式和试发状态。

## 状态模型

标准状态为：

- `IDLE`
- `WORKING`
- `WAITING`
- `SUCCESS`
- `ERROR`

接口也允许符合命名规则的自定义状态。当前主题没有对应映射时，自定义状态会使用空闲效果。

## 安全建议

- 只向应用当前公布的本机地址发送请求；
- 不要在状态来源、会话名或自定义字段中放入密码、令牌或代码正文；
- 如启用了访问令牌，不要把令牌提交到仓库或公开日志；
- 自定义脚本失败时，不应阻断原 AI 工具的正常工作。

完整请求、响应和字段契约见项目中的[Hook API 使用指南](../../specs/hook-api.md)。该文档属于开发者参考，内容可能包含用户界面不会展示的内部字段。
