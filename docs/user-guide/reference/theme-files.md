# 主题文件参考

> 本章面向需要分享、版本管理或手工编辑主题的高级用户。大多数主题可以直接通过“主题创作器”完成，无需编辑 JSON。

AI Light 用户主题使用 `.ailight-theme.json` 文件。主题主要包含：

- 主题名称和版本；
- 可复用的灯光与声音效果；
- 任务状态到效果的映射。

## 使用原则

- 标准状态为 `IDLE / WORKING / WAITING / SUCCESS / ERROR`；
- 可以增加自定义状态；
- 未映射状态使用空闲效果；
- 内置主题不能被同名用户主题覆盖；
- 导入时会同时检查 JSON 结构、字段、效果引用和参数范围；
- 设备能力不足时，部分效果可能无法应用。

## 建议的编辑方式

1. 先在 AI Light 中以现有主题创建副本。
2. 用主题创作器完成大部分调整。
3. 导出或保留主题文件后，再进行手工编辑。
4. 每次只修改一类参数，并重新导入验证。
5. 分享前在实体设备上检查五种标准状态。

完整字段、示例和校验规则见项目中的[主题格式指南](../../specs/theme-format.md)。该文档属于高级格式规范，其中的字段名不会全部出现在普通用户界面中。
