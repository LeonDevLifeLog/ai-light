# 术语表

| 术语 | 含义 |
|---|---|
| AI Light 应用 | 安装在电脑上的桌面软件 |
| AI Light 设备 / 状态灯 | 通过蓝牙接收灯效与声音的实体设备 |
| AI 编程工具 | Claude Code、Codex 等产生任务状态的工具 |
| 状态 | 空闲、工作中、等你回复、已完成或出错了 |
| 主题 | 把状态转换成灯光、动画和声音的方案 |
| 试听 | 手动模拟状态或重播当前灯效 |
| 接入 | 把 AI 编程工具的任务状态自动同步到 AI Light |
| Hook | AI 编程工具在特定事件发生时调用的扩展命令 |
| 配套组件 | 在 AI 编程工具和 AI Light 应用之间转换、投递状态的本机程序 |
| 自动重连 | 蓝牙意外断开后，应用自动尝试恢复设备连接 |
| 最近活动优先 | 多个工具同时运行时，最后上报状态的工具接管状态灯 |

## 标准状态代码

普通界面主要使用中文状态名。高级接口和主题文件可能使用以下代码：

| 用户界面 | 高级代码 |
|---|---|
| 空闲 | `IDLE` |
| 工作中 | `WORKING` |
| 等你回复 | `WAITING` |
| 已完成 | `SUCCESS` |
| 出错了 | `ERROR` |
