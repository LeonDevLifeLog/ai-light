# 快速开始

本章的目标是完成一次完整验证：安装 AI Light 应用，连接 AI Light 设备，接入一个 AI 编程工具，并看到真实任务状态出现在状态灯上。

## 1. 安装 AI Light 应用

1. 从正式发布渠道取得与你的操作系统匹配的安装包。
2. 按系统提示完成安装并启动 AI Light。
3. 如果系统询问是否允许使用蓝牙，请选择允许。

各平台安装包格式、最低系统版本以及签名状态以对应版本的发布说明为准。不要用项目源码的开发启动命令代替普通安装。

### 首次启动时可能看到的系统提示

- **macOS**：可能要求确认打开来源，并授予蓝牙访问权限。
- **Windows**：可能显示应用来源或安全确认，并要求系统蓝牙可用。
- **Linux**：需要系统蓝牙服务正常运行，桌面环境也必须允许当前用户访问蓝牙。

如果拒绝了蓝牙权限，可前往系统设置重新授权，然后重新打开 AI Light 应用。

## 2. 连接 AI Light 设备

1. 给 AI Light 设备供电并让它靠近电脑。
2. 确认电脑蓝牙已经开启。
3. 在 AI Light 左侧选择“设备”。
4. 等待应用查找附近设备；也可以选择“重新查找设备”。
5. 在兼容设备旁选择“连接”。
6. 页面出现“已连接”且侧栏底部显示“设备已连接”即表示成功。

第一次连接成功后，应用会记住该设备。以后启动时会尝试自动连接。

如果列表中没有设备，请检查供电、距离和蓝牙权限，然后查看[找不到设备](./troubleshooting.md#找不到-ai-light-设备)。

## 3. 先用“试听”验证状态灯

1. 在左侧选择“试听”。
2. 依次选择“工作中”“等你回复”“已完成”和“出错了”。
3. 检查应用中的状态是否变化，并观察 AI Light 状态灯的灯光或提示音。
4. 选择“停止灯效”可停止灯光和蜂鸣，并把状态恢复为空闲。

“试听当前灯效”只会重新播放当前效果，不会改变软件状态。没有连接设备时，仍可在应用里模拟状态，但实体状态灯不会变化。

## 4. 连接一个 AI 编程工具

1. 在左侧选择“接入”。
2. 在 Claude Code、Codex、Qoder、TraeCode 或 WorkBuddy 卡片中选择“连接”。
3. 等待按钮执行完成。
4. 卡片显示“配置已写入”即表示 AI Light 已完成配置文件写入。
5. 按卡片展开的“下一步”完成目标工具侧设置：Codex 需要在“设置 → Hooks”中信任新 Hook，TraeCode 需要在“设置 → Hooks”中开启全局 Hook；Qoder 无需其他操作。Claude Code 通常也无需额外设置。

首次连接时，AI Light 可能需要通过 npm 安装配套组件。电脑必须能运行 Node.js 和 npm，并能访问 npm 软件源。AI Light 会合并必要配置，不覆盖其他 Hook。

如果出现 npm 或配套组件错误，请查看[AI 编程工具无法连接](./troubleshooting.md#ai-编程工具无法连接)。

## 5. 完成第一次真实亮灯

1. 保持 AI Light 应用运行。窗口可以关闭，应用仍会驻留系统托盘。
2. 启动刚刚连接的 Claude Code、Codex、Qoder、TraeCode 或 WorkBuddy。
3. 发起一个真实任务。
4. 返回 AI Light 的“状态”页面，确认状态变为“工作中”。
5. 当工具请求确认或授权时，状态应变为“等你回复”。
6. 任务结束后，状态应变为“已完成”或“出错了”。

主题会改变具体颜色、动画和声音，所以请以状态文字和整体状态变化为准，不要只用某一种颜色判断是否成功。

## 完成检查

以下项目全部成立，即表示基础配置完成：

- “设备”页面显示已连接；
- “试听”可以控制实体状态灯；
- “接入”页面至少有一个工具显示配置已写入；
- 真实任务开始后，“状态”页面自动变化；
- 实体状态灯与应用状态同步。
