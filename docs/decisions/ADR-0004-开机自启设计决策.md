## 背景

产品形态为托盘常驻（KAD-06）：关窗 = 隐藏、退出只经托盘。作为常驻工具，"登录系统后灯效服务自动就位"是核心 SHOULD。此前 `config.json` 的 `autostart` 字段仅持久化（`update_config` 直接写缓存），Settings 页展示禁用态（「待平台支持」），**没有触碰任何 OS 登录项**——即配置项存在但完全不生效。

## 决策（5 项，全部确认）

### D-01 OS 登录项 = 唯一事实源；`config.autostart` = 启动校准缓存

**确定：开机是否自启以 OS 登录项（macOS LaunchAgent / Windows Run key / Linux XDG autostart）为真值。**

`config.autostart` 只做启动校准缓存：每次启动用 `is_enabled()` 校准并写回，二者短暂不一致（用户手动改系统登录项、配置文件被外部编辑）时以 OS 为准。

理由：OS 登录项是唯一会被系统实际执行的注册点，config 文件只是应用侧视图；以 config 为准会导致"开关显示开了但系统不执行"的假象。

### D-02 不引入 JS 绑定，统一走 Rust `update_config`

**确定：不安装 `@tauri-apps/plugin-autostart` 前端绑定，自启动变更统一经 `update_config(autostart)`。**

时序：**先 OS enable/disable → 成功才写 config + emit `config-changed` → 失败返回 `AUTOSTART_FAILED`，config 保持原值。**

理由：前端直调 `enable()/disable()` 会绕过 config 一致性（config 不更新、`config-changed` 不 emit），产生 UI 与持久化漂移。

### D-03 插件选型：官方 `tauri-plugin-autostart` v2，macOS 用 LaunchAgent

**确定：`tauri-plugin-autostart = "2"`（当前 2.5.1，`auto-launch 0.5` 内核），macOS 用 `MacosLauncher::LaunchAgent`（默认）。**

> **事实修正**：官方 crates.io 版本**不存在** `macos-launch-at-login` feature（2.5.1 features 为空）。macOS 端走 LaunchAgent（写 `~/Library/LaunchAgents/*.plist`）或 AppleScript 登录项，**不是 SMAppService**——因此**不要求正式签名**，ad-hoc 签名的 dev / CI 构建可直接生效。

### D-04 启动校准（setup 内）

**确定：插件注册后，应用 `.setup()` 内调用 `is_enabled()` 校准写回 config；读取失败不阻塞启动，保留本地缓存值并记日志。**

可行性依据：Tauri v2 插件 `setup` 在 `Builder::build` 阶段（`initialize_plugins`）执行，早于应用 `.setup()` 回调——插件 `AutoLaunchManager` state 已就绪，可安全调用（已在 tauri 2.11.5 源码核对）。

### D-05 登录启动参数 `--autostart`（预留）

**确定：注册插件时传入 `--autostart` 参数，使登录启动可辨识；本期登录启动与手动启动行为一致（显示主窗口），后续"登录启动不弹窗"仅需一行判断。**

## 备选方案（否决）

| 方案 | 否决原因 |
|---|---|
| 前端直调插件 JS 绑定 | 绕过 config 一致性，UI 与持久化漂移 |
| macOS 用 SMAppService | 要求正式签名 + `/Applications` 部署，与当前 ad-hoc CI 冲突；V2 评估 |
| config 为唯一事实源（仅持久化字段） | 系统不执行，开关形同虚设（即现状，否决） |

## 后果

- ✅ 真实切换闭环：Settings 开关 ↔ OS 登录项 ↔ config 双向一致（启动校准兜底）
- ⚠️ 平台细节待实机（U-08）：mac Ventura+ 首次启用弹"在后台运行"通知；app 移动后 plist 路径可能失效；Linux 桌面环境对 XDG autostart 支持不一
- ✅ `AUTOSTART_FAILED` 错误码进入 IPC 契约（ipc-contract §4），失败可感知、可回滚
