准备工作

开始前确认客户端、灯牌和系统蓝牙都已准备好。

  • ✓启动 AI-Light安装并打开桌面客户端。关闭主窗口后，应用仍会驻留在系统托盘。
  • ✓唤醒状态灯确保灯牌已供电，并放在电脑附近。首次连接建议控制在 1 米内。
  • ✓打开系统蓝牙macOS、Windows 或 Linux 均需允许 AI-Light 使用蓝牙。

5

完成首次验证

先用应用内试听确认设备，再启动一次真实 AI 任务确认完整链路。

① 先验证灯牌

打开「试听」，依次点击「工作中」和「已完成」。灯牌应立即显示对应灯效。

② 再验证工具

在已接入的工具中发起一个简单任务，返回「状态」查看来源与灯效是否同步变化。

✓看到灯效变化就完成了多个工具同时运行时，最后上报状态的工具接管灯效，这是固定的「最近活动优先」规则。

7

遇到问题时

沿着「设备 → 接入 → 状态」逐层检查，通常能快速定位问题所在。

灯牌没有任何反应

先在「设备」确认状态为已连接，再去「试听」触发工作中。如果试听也没有反应，请重新连接设备；如果试听正常，则继续检查工具接入。

工具运行了，但灯效没有变化

在「接入」确认对应工具为已连接，并重新检测运行环境。Codex 首次执行 Hook 时，还需要按其安全提示确认信任。

成功状态为什么一直亮着

终态是否自动回到空闲由主题决定。Default 经典主题会保留成功与错误状态，直到收到下一次状态事件。

想快速测试 Hook API

普通使用不需要调用 API。开发调试时可从「设置」打开当前服务的接口文档，端口由 AI-Light 自动管理。

✓

设置完成，可以开始工作了

让 AI-Light 留在系统托盘中。下一次工具开始工作、等待输入或完成任务时，你无需切换窗口也能立即看到。
